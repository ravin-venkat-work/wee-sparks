# ✨ Wee Sparks

An adaptive, audio-first numeracy and literacy learning platform built for Primary 1, 2, and 3 children (ages 4–7) in Northern Ireland, mapped directly to the **CCEA Foundation Stage & Key Stage 1** curriculum.

## Core Principles
- **CCEA Curriculum Aligned:** Built around NI Linguistic Phonics and practical number sense rather than generic English curriculum standards.
- **Zero Runtime AI:** 100% deterministic, offline-capable student runtime with pre-validated content packs generated via an offline Admin Content Studio.
- **Child-Safe & Privacy-First:** Designed for the UK ICO Children's Code with local-first progress storage and zero third-party tracking.
- **Parent Bridge:** Plain-English weekly progress summaries, real-world offline activity prompts, and 1-click printable practice sheets.
